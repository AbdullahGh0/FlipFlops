Latch or flip-flop?

Both store one bit. The difference is when they are allowed to change.

Latch level-triggered

While the enable (clock) input is at its active level, the latch is transparent: every change on the input passes straight through to Q. When the enable goes inactive, it holds the last value.

Think of a door left open: anything that walks by while it is open gets in.

Flip-flop edge-triggered

It looks at its inputs only at the instant the clock changes (rising edge ↑ or falling edge ↓). Between edges, the inputs can do anything; Q does not move.

Think of a camera: it takes one snapshot at the click and ignores everything else.

How a latch becomes a flip-flop

While CLK = 0 the master is open and follows D, the slave is closed. When CLK rises, the master closes (freezing D) and the slave opens, copying that frozen value to Q. Net effect: Q only takes D at the rising edge.

Heads-up: some textbooks (Mano, for example) call a gated latch a "clocked flip-flop". If your slides draw a gated latch and call it a flip-flop, that is the same circuit with a different name.

    Truth, characteristic and excitation tables

    Each table answers a different question. Know which question, and the table almost writes itself.

    Truth / function table

    "What does each input combination do?" Compact: inputs → next state written as 0, 1, Q (hold) or Q′ (toggle).

    Characteristic table

    "Given present Q and inputs, what is Q⁺?" Present state becomes a column. Used for analysis; a K-map of it gives the characteristic equation.

    Excitation table

    "I want Q to go from this to that: which inputs?" The characteristic table read backwards. Used for design (counters, state machines).

    The family tree: every flip-flop is an SR with a fix

    SR ── problem: S=R=1 is forbidden ├─ D fix: R = S′ (inverter) → can never be 11, only set/reset ├─ JK fix: feed Q and Q′ back → 11 now means TOGGLE │ └─ T tie J = K = T → 0 hold, 1 toggle └─ (D = JK with K = J′, T = JK with J = K)
